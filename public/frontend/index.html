Precios por kilogramo

Define el precio semanal de compra/venta para cada producto

¿Cómo funciona el precio semanal?

1
¿Cuándo se cambia?
Cada jueves en la mañana el administrador revisa y actualiza el precio base del kilogramo según el mercado.
2
¿Qué pasa si no se cambia?
Si el jueves no se registra un nuevo precio, el sistema mantiene automáticamente el precio de la semana anterior. Las operaciones continúan sin interrupción.
3
Precio al productor vs. precio de venta
El precio base es lo que recibe el productor. Al vender a un comerciante, el operario cobra: EL PRIMO → precio base exacto  ·  Otros → precio base + $100/kg.
Descuento de transporte
El flete se descuenta automáticamente al cerrar cada ruta según los kilogramos transportados. No se registra aquí.
Resumen rápido
Jueves: revisar y actualizar precio base
Sin cambio: precio anterior sigue activo
Productor cobra: precio base (según ruta)
EL PRIMO paga: precio base exacto
Otros comerciantes: precio base + $100/kg
